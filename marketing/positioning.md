# Positioning — the one-pager every word of marketing derives from

## The category (own a NAME, not a feature list)
We are not "a better merge tool". We are the first **semantic merge** for git.
Say "semantic merge" relentlessly until the words belong to us. The moment a
category has a name, whoever named it is its default leader.

## The enemy (every great launch has one)
**The 1979 merge.** git still merges with the logic of diff3 — line arithmetic
from the punch-card era, applied to your ASTs. The enemy is never a company or
a person; it's the outdated default everyone tolerates.

## The one-liner (say it the same way everywhere)
> icr-merge teaches git to read code, not lines.

Variants by audience:
- Git users: "Renames stop causing conflicts. Broken-but-'clean' merges get caught."
- AI builders: "Agents merge at machine speed. Line merges silently fuse their
  edits into code nobody wrote. This is the merge layer built for that world."
- Skeptics: "Worst case, it behaves exactly like git does today. The floor is
  git; only the ceiling moved."

## The named villain-moment (make the failure memorable)
**"The silent bad merge"** — a merge with no conflict markers that ships broken
code. Give the failure a name and people start seeing it everywhere; every
time they do, they think of us.

## Proof stack (in the order that convinces)
1. The 15-second rename demo (seeing beats believing)
2. The parse guarantee + git-fallback floor (removes all risk)
3. 12,671 assertions / 5-language fuzzing / dogfooded (we're serious)
4. MIT + 30-second install (nothing to lose)

## Audience ladder (who converts whom)
solo dev (feels pain) → tech lead (adds .gitattributes, converts a team)
→ agent-framework author (embeds the library, converts a userbase)
Marketing always aims one rung up from whoever's listening.

## Voice
Builder, not brand. First person. Numbers over adjectives. Admit limits
plainly (JS deepest, others structural, rest = git floor) — every honest
limitation buys credibility we spend on the big claims. Never say
"revolutionary", "game-changer", "blazingly". Show a merge instead.

## The two-act arc (don't spoil act two)
Act 1: icr-merge — universal git pain, no education needed. Builds audience.
Act 2 (2-3 weeks later): "CRDTs have guaranteed convergence for 20 years.
For AI-written code, convergence is the bug." — health-gated convergence,
Hivecode, the substrate. Act 1's tweet 6 plants the seed on purpose.
